# Serverless Cloud Resume on AWS

## Overview
Built a fully serverless cloud portfolio website using AWS services and CI/CD automation.

## AWS Services Used
* Amazon S3
* Amazon CloudFront
* AWS Lambda
* Amazon DynamoDB
* Amazon API Gateway
* AWS IAM

## DevOps & Automation
* GitHub
* GitHub Actions
* OIDC Federation

## Key Features
* Serverless architecture
* Visitor counter API
* Automated deployments using GitHub Actions
* Secure authentication using OIDC federation
* Global content delivery through CloudFront

## Skills Demonstrated
* Serverless application architecture
* CI/CD automation
* Cloud security
* API development
* Infrastructure deployment
